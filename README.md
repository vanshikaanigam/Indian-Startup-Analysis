# 🚀 Indian Startup Analysis 

## 📌 Project Overview

India has emerged as one of the world's fastest-growing startup ecosystems, with thousands of startups transforming industries such as FinTech, EdTech, E-commerce, HealthTech, and SaaS. Understanding startup trends, funding patterns, sector growth, and geographic distribution can provide valuable insights for entrepreneurs, investors, and policymakers.

This project analyzes Indian startup data using SQL and Power BI to uncover trends in startup growth, industry sectors, founding years, locations, and IPO activities.

## 🎯 Business Problem Statement

With the rapid expansion of India's startup ecosystem, investors and business leaders need data-driven insights to identify emerging sectors, startup hubs, and growth opportunities.

The objective of this project is to analyze Indian startup data and answer key business questions related to startup distribution, industry trends, founding patterns, and regional growth. The insights generated can help stakeholders understand where innovation is happening and which sectors are driving India's startup economy.
